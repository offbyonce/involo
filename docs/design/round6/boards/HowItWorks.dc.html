2Flows, then checklists

Airline crews don’t read their way through setting up an airplane. They do a flow: a fixed sweep across the panels, setting each switch from memory in the same order every time. The order follows the flight deck itself, so nothing is skipped by accident.

Then comes the checklist. It doesn’t do the work again. One pilot reads each item, the challenge; the other looks, confirms it’s set, and answers, the response. A checklist only catches what the flow missed, so it’s short.
