New panel controls

Pack format 6 adds four controls for flight decks other than the 737. The app draws each one from the pack’s data, in the panel colors only, in the same three states as today’s controls: resting (neutral outline), set by this step (blue, with the target position in bold; ◆ only when a decision step’s answer set it), and depends on a choice (dashed blue, no position). Shown at twice the panel’s size.

Push/pull knob

kind: push_pull_knobA rotary knob that is also pushed in or pulled out. Pulled out, a second ring shows the knob standing proud; pushed in, a dot sits in its center.
Resting: pushed in
Set by this step: PULL
Set by this step: PUSH
Depends on a choice

Pushbutton with legends

kind: legend_pushbuttonA square button with two legends that light. The pack names each legend and its light color (amber, red, green, blue or white); the app picks the color.
Resting: no legend lit
Set by this step: OFF, lit
A legend the step expects on
Depends on a choice

Rocker

kind: rockerA two-way switch that tips about its middle. The pressed end is filled.
Resting: OFF pressed
Set by this step: ON

Keypad

kind: keypadA block of keys. The key or keys the step presses are the step’s color; the others stay neutral.

On a panel

An invented panel. Its outline is angled (a panel may give its own outline points), the step sets ALT to PULL, and HDG shows the keyboard focus ring: every drawn control can be reached with Tab, the step’s controls first.
