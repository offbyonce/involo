# `cdu.yaml`

Schema: `schemas/cdu.schema.json`. [All files](index.md).

## The file

`cdu.yaml`: page-by-page CDU walkthroughs, each with the text and live flight values the screen shows at every step. A step's `opens` names one, and the app opens it from that step in the slide-out, with the flight's values filled in.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `walkthroughs` | list of [CduWalkthrough](#cduwalkthrough) | yes |  | Every walkthrough. |

## CduWhen

Shows one group of parts when flight values are known and another when they are not, e.g. `<SEL>` beside a runway, or a placeholder until there is a runway. Does not nest.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `otherwise` | list of [CduInline](#cduinline) |  |  | The parts shown when any of them is not; nothing when left out. |
| `show` | list of [CduInline](#cduinline) | yes |  | The parts shown when every field in `when_known` is known. |
| `when_known` | list of [FieldId](#fieldid) | yes |  | Every one of these must be known for `show` to appear. |

## CduStyle

How text appears on the CDU screen.

| Value | What it means |
| --- | --- |
| `data` | System data the pilot does not enter. |
| `accent` | Values the system has calculated or accepted. |
| `user` | Values the pilot enters. |

## FieldId

A flight field's id, e.g. `zfw`: one of the fields the pack defines in `flight.yaml` (decision 0029), or one of the app's own, [`FieldId::MANUAL`] and [`FieldId::ROUTE_LEG`]. Saved flights key their values by it, as text.

## CduForm

How a value is written on the CDU screen. The forms are the app's: they describe ways of writing a value, not an aircraft. A value that doesn't read as its form shows as it is.

| Value | What it means |
| --- | --- |
| `wind` | A wind, `ddd/sss`, with a degree sign after the direction: `270°/045`. |
| `temperature` | A temperature in degrees Celsius, in Fahrenheit then Celsius: `-62°F -52°C`. |
| `temperature_change` | A temperature difference in degrees Celsius, signed, in Fahrenheit then Celsius: `+4°F +2°C`. |
| `utc_time` | A UTC time, `10:00`, as hours, minutes and tenths of a minute: `1000.0z`. |
| `month_day_year` | A date, `2025-11-13`, as month, day and year: `NOV13/25`. |
| `month_day_range` | Two dates, `2025-10-30/2025-11-27`, as month and day each, then the second's year: `OCT30NOV27/25`. |

## RouteLegPart

Which half of a route row a field shows.

| Value | What it means |
| --- | --- |
| `via` | The left half: the way the leg is flown. |
| `to` | The right half: where the leg ends. |

## RouteLegCount

A count the app works out from the route.

| Value | What it means |
| --- | --- |
| `pages` | How many pages the route legs and departure need, at least 1. |
| `overflow` | How many route rows do not fit on the first page. |

## CduInline

Text or a live value, in any style. Mix several in a row to style them differently.
