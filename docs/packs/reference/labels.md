## The file

`labels.yaml`. Every key is optional; a key left out keeps the app's default. Lists (`seats`, `roles`, `find_examples`, `glossary_exceptions`, `side_words`, `plain_words`) replace the default list; `position_words`, reference `groups` and `basis_tags` are merged with the defaults by key.
