# `notes.yaml`

Schema: `schemas/notes.schema.json`. [All files](index.md).

## The file

`notes.yaml`: how-to instructions and explanations that several steps share, each named by the steps that use it.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `explain` | list of [ExplainNote](#explainnote) |  |  | Shared explanations, named by a step's `explain`. |
| `how` | list of [HowNote](#hownote) |  |  | Shared "How to do it" instructions, named by a step's `how`. |

## ExplainNote

A shared explanation of a test or action.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `check` | text |  |  | What to check: the step's Check, when the step has no `check` of its own. |
| `check_detail` | text |  |  | More on the check, shown below it when the step has no `check` of its own. |
| `failure` | text |  |  | What a bad result can mean. |
| `id` | text | yes |  | Unique in the pack; a step's `explain` names it. |
| `if_not` | text |  |  | What to do when the check fails: the step's If not, when the step has no `if_not` of its own. |
| `if_not_detail` | text |  |  | More on the If not, shown below it when the step has no `if_not` of its own. |
| `success` | text | yes |  | What a good result looks like. |
| `what` | text | yes |  | What the test or action is: the "What it is" line under the step's "How to do it". |
| `why` | text | yes |  | Why it is done: the step's Why, when the step has no `why` of its own. |

## HowNote
