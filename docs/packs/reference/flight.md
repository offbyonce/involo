## The file

`flight.yaml`: the pack's Flight pages and its flight fields, in order. The pack gives content and grouping only; the app decides how every part looks.

| Field | Takes | Required | Default | What it is |

| `overview` | list of [FlightOverviewRow](#flightoverviewrow) |  |  | The Overview page's "This flight" rows. Without them, one row per Flight page that has fields: its title, its first two values and its sub-line. |
| `pages` | list of [FlightPage](#flightpage) |  |  |  |

## FlightOverviewRow

A "This flight" row on the Overview page, linking to a Flight page by its title. `value` and `description` are parts written with `{field}` for a field's value as typed, `{field:grouped}` for a number with its thousands grouped, and `{unit}` for the flight's unit. A part shows when any field it names has a value, its other fields reading "—"; value parts join with " · ", description parts with a space.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `description` | list of text |  |  |  |
| `empty` | text |  |  | The description when no description part shows. |
| `label` | text | yes |  |  |
| `page` | text | yes |  | The Flight page the row links to. |
| `value` | list of text |  |  |  |

| `note` | text |  |  |  |

| `title` | text |  |  |  |
