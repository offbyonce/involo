## AliasKind

What an alias renames. Covers everything the previous release saved.

| Value | What it means |
| --- | --- |
| `step` | `to` is a step id. |
| `briefing_item` | `to` is a briefing item id. |
| `blank` | A value typed into a blank. `to` is `<step-id>#<n>`, counting blanks from 0. |
| `panel_state` | `to` is a panel state id. |
| `option_value` | A chosen option. `from` and `to` are `<option>:<value>`. |
| `fill_field` | A saved flight value. `to` is one of the pack's flight fields. |
| `list` | `to` is a list id. |
| `phase` | `to` is a phase id. |
| `zone` | `to` is a zone id. |
