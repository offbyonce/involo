# `panel-states.yaml`

Schema: `schemas/panel-states.schema.json`. [All files](index.md).

## The file

`panel-states.yaml`: the starting points a pilot can pick on the Start page, each with the steps it counts as already done or skipped.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `states` | list of [PanelState](#panelstate) | yes |  | The states, in the picker's order. |

## PanelState

A ready-made point to start from, with earlier steps already accounted for.

| Field | Takes | Required | Default | What it is |
| --- | --- | --- | --- | --- |
| `description` | text | yes |  | What it starts from, in words. The app does not show it today. |
| `done` | list of [StepId](#stepid) |  |  | Steps ticked when this state is chosen, unless already ticked or skipped; choosing another state takes those ticks back. |
| `id` | text | yes |  | The state's id, which a flight records and aliases can rename. |
| `phase` | text | yes |  | The phase to open. |
| `set` | map of text |  |  | Options this start selects. |
| `skip` | list of [StepId](#stepid) |  |  | Steps skipped when this state is chosen, unless already ticked or skipped; choosing another state takes those skips back. |
| `title` | text | yes |  | Its name in the Start page's panel-state picker. |

## StepId

A stable step id: `<pack-id>.<phase>.<short-name>`, e.g. `demo-aircraft.preflight.irs-mode`. An id never changes once published, even if the step is reworded or moved to another phase.
