memory · order

1. FINAL APPROACH … ESTABLISH LANDING CONFIGURATION AND IN-TRIM CONDITION EARLY
2. STABILIZER … TRIM MANUALLY
3. IF RUNAWAY STILL CONTINUES … GRASP AND HOLD THE STABILIZER TRIM WHEEL
4. MANUAL TRIM … TWO-PILOT EFFORT MAY BE USED. LOWER AIRSPEED EASES THE LOAD
In order: IF RUNAWAY STILL CONTINUES … GRASP AND HOLD THE STABILIZER TRIM WHEEL › STABILIZER … TRIM MANUALLY › MANUAL TRIM … TWO-PILOT EFFORT MAY BE USED. LOWER AIRSPEED EASES THE LOAD › FINAL APPROACH … ESTABLISH LANDING CONFIGURATION AND IN-TRIM CONDITION EARLY
Why: An uncontrolled trim runaway makes the airplane harder to control. Controlling the airplane comes first, then trim cutout stops the input.
Links: If runaway still continues · Memory items (#/phase/memory)
